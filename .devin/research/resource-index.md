# Resource index: high-signal GitHub repos for agent work

Curated from caleb.is-a.dev/blog/amazing-github-repos (batch-9, 2026-11-13).
Reach for these BEFORE improvising: each entry says when it applies and which
bundle area it feeds. Verify a repo still exists/active before deep use.

| Repo | What it is | Reach for it when | Bundle area |
|---|---|---|---|
| `papers-we-love/papers-we-love` | CS papers by topic, community-discussed | Need a primary source on algorithms/ML/security before designing | `researcher`, `.devin/docs/` ADRs |
| `donnemartin/system-design-primer` | Scalability, DBs, caching, arch; Anki cards | System-design questions, interview prep, capacity planning | `performance`, capacity mgmt, reviews |
| `public-apis/public-apis` | Collective list of free APIs | Need a free API for a feature/integration spike | `api-design`, extension prototyping |
| `sindresorhus/awesome` | Meta-index of awesome-* lists | Hunting a tool/library in any domain | all skills, onboarding |
| `rasbt/LLMs-from-scratch` | Build a ChatGPT-like LLM in PyTorch, step by step | Teaching internals, verifying model mechanics before post-training | `ai-tools` |
| `eriklindernoren/ML-From-Scratch` | NumPy implementations of ML algos | Understanding ML fundamentals without black-box libs | `ai-tools`, `data-analyst` |
| `codecrafters-io/build-your-own-x` | Guides to rebuild DBs/OS/langs/web servers | Learning-by-building, validating mental models | `architecture`, spikes |
| `ripienaar/free-for-dev` | SaaS/PaaS/IaaS free tiers | Cost-constrained tooling decisions | `cost-optimization` |
| `EbookFoundation/free-programming-books` | Free books by language/topic | Structured learning path for a domain | onboarding, skill gaps |
| `nilbuild/developer-roadmap` | Interactive roadmaps (FE/BE/DevOps/AI) | Career/skill planning questions | planning, capacity |
| `ossu/computer-science` | Self-taught CS curriculum | Full CS fundamentals gap-fill | long-term learning |
| `kilimchoi/engineering-blogs` | Curated eng blogs from real teams | How production teams solve scaling/problems | `researcher`, reviews |
| `TheAlgorithms/*` | Algo/DS implementations across languages | Reference implementation for an algorithm | `performance`, spikes |
| `btw-so/open-source-alternatives` | OSS alternatives to SaaS | Replacing paid tools with self-hosted | `cost-optimization`, extensions |
