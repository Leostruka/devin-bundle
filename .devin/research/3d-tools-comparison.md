# 3D Tools Comparison: Agent-Drivable Stack to Replace spline-operator

**Date:** 2026-09-29
**Scope:** evaluate 3D creation/manipulation tools across 6 axes (hyper-realism, cartoon/stylized, creative/procedural, animation/rigging, characters, environments) plus agent-drivability and cost/license. Two research fronts:

- **Frente A** (159 sources): commercial/proprietary + AI-3D SaaS.
- **Frente B** (140 sources): free/open-source/self-contained, per user constraint (no paid dependencies; manipulable, self-contained).

**Source criteria:** official docs/release notes/pricing, SIGGRAPH/arXiv papers, published benchmarks (Puget, Blender Open Data, 3D Arena, T3Bench), studio postmortems/GDC talks, professional outlets (80.lv, fxguide, CG Channel, Polycount). No SEO blogs/listicles. Full citation list in Appendix A (299 records).

---

## 1. Executive summary

**Recommendation: Blender-centric open stack (Frente B).**

- **Core DCC:** Blender (GPL-3.0; output unencumbered per blender.org/about/license). Covers all 6 axes at production grade: Cycles/EEVEE Next (hyper-realism), Grease Pencil 3 + Line Art + Malt (cartoon/NPR), Geometry Nodes + Sverchok + Infinigen (procedural), NLA/Rigify + layered-actions roadmap (animation), sculpt/retopo/hair-curves + MPFB2 (characters), Geo-Nodes scattering + BlenderGIS + Infinigen (environments). Oscar-winning feature *Flow* was made entirely in Blender, EEVEE-rendered on a single PC.
- **Agent drivability: best in class.** `bpy` scripts everything; `blender -b -P script.py` runs headless; `pip install bpy` embeds Blender as a CPython module with no app process; `mcp-for-blender` (ahujasid) provides a ready MCP bridge over a socket addon.
- **AI-3D generation (self-hosted):** ComfyUI (GPL, HTTP/WebSocket workflow API) + ComfyUI-3D-Pack wrapping TRELLIS (MIT), TripoSG (MIT), InstantMesh (Apache-2.0), Hunyuan3D-2.1 (Tencent community license). Open models now sit in the top quality tier per 3D Arena human-vote benchmarks.
- **Glue/interchange:** OpenUSD (pxr Python API, permissive license) + PyMeshLab/trimesh/Open3D/pyrender for scripted mesh processing.
- **Realtime delivery (if needed):** Godot 4 (MIT, --headless CLI, godot-mcp ~173 handlers).

**Alternative (if paid is later acceptable):** Houdini Indie + Unreal Engine 5. Strongest procedural (VEX/HDA/PDG/Solaris/Copernicus) and strongest realtime/world-building (Nanite/Lumen/PCG) with excellent drivability (hython, HAPI, houdini-mcp 166 tools; UnrealEditor-Cmd Python + Remote Control HTTP/WS + unreal-mcp 101 tools). Cost: Houdini Indie $299/yr (<$100K revenue), UE free <$1M lifetime then 5% royalty.

**spline-operator verdict: SUBSTITUIR.** See section 6.

## 4. Drivability detail (decisive criterion)

Agent-drivable tiers, from cited docs:

| Tier | Mechanisms | Tools |

## 6. Verdict: spline-operator

**SUBSTITUIR.** Evidence:

1. **Spec-observed:** produces useless artifacts for the 6 target axes (premise of this research).
2. **Tool ceiling, not bridge defect:** Spline is a web-scene editor; its own docs show AI 3D generation is a paid-credits feature that orchestrates third-party models (Hunyuan3D default, Hunyuan 3.1 Pro, Trellis 2). The incumbent therefore adds a paid middleman over open models we can drive directly at $0.
3. **Drivability asymmetry:** the MCP bridge (36 tools) drives a weak tool; equivalent-or-better bridges exist for stronger free tools (mcp-for-blender, godot-mcp, houdini-mcp).
4. **Front-B fit:** replacement keeps everything self-contained: Blender (bpy/headless/MCP) + ComfyUI-3D-Pack (HTTP workflow API) cover generation, editing, rendering, NPR, characters, environments.

Keep spline-operator code dormant (do not delete per repo norms), supersede with a Blender MCP/bpy integration.
