# Reels batch-3 evals - external items worth tracking

Date: 2026-11-05. All notes, no integrations. Survey:
`.devin/research/2026-11-05-reels-batch3-survey.md`.

## Watchlist (models)

- **bloc "Dia"** - speech-to-speech voice model (Jack Dorsey / bloc labs).
  No text stage at all: hears speech, reasons speech, answers speech;
  preserves emotion, pauses, sarcasm. Trained from scratch on recorded
  human conversations. Requires M4 Max Mac -> gated, watch only. Same
  category as nvidia/personaplex-7b (already in ai-tools watchlist).
- **Bonside-2 27B (ternary)** - 27B-param reasoning model, 272k ctx,
  ternary quantization -> local-capable per the reel. Candidate for
  local-inference eval IF open weights/tooling exist; verify license
  before any work.

## Infra evals (map to existing lanes)

- **OpenVQ** - open-source context/memory DB for agents (single place for
  knowledge, user memories, reusable experience). Maps to the memory lane:
  `memory-retrieval`, `context-folding`, laya memory. Evaluate only if a
  real repo materializes; current memory hooks already cover the need.
- **Google Artemis** - prompt -> real mobile automations via MCP (runs in
  Codex/Claude Code, captures logs/screens while working). Maps to the
  computer-use adb backend (`--env`, `terminal.py exec` on Android). If
  released, could be a backend option; current adb path already covers
  taps/text/shell.
- **AWS agent-inbox ("pizza bot")** - mailbox/inbox for background agents
  so work continues while the user does other things. Maps to
  `afk-loop` + `sentinel` + scheduled-turns; an inbox primitive would be a
  thin layer, not a skill. Revisit if a concrete OSS artifact appears.

## Reference implementations

- **MoneyPrinterTurbo** - OSS automated short-video pipeline (script ->
  stock footage -> TTS -> captions -> batch render). `shorts-factory`
  already encodes this pipeline end-to-end; MoneyPrinterTurbo is the
  reference impl to compare against if shorts-factory ever needs a gap
  audit.
- **VoiceStudio** - local ElevenLabs-equivalent: voice clone, TTS,
  dubbing, 600+ languages, runs on own machine. Candidate TTS backend for
  `voicebox`; tracked in the existing `.devin/handoffs/C4-voicestudio-path.md`.
- **GlobalRow** - public job board, 367k+ listings, company/sector
  filters, per-application status tracking. Data source for the
  job-apply lane (R2-02: copywriter + reviewer chain) if that lane is
  ever built out.
