If you make a prediction, you get an answer. If you compare it to the correct answer, you get an error. If you measure how bad that error is, you get a loss. If you use calculus to figure out how each weight affects that loss, you get a gradient. If you send those gradients backward through the network, you get backpropagation. If you use backpropagation to change each weight, you get gradient descent. If you run the network again with its new weights, you get a better answer.
