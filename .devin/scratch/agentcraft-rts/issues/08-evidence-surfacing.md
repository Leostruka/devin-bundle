# 08 - evidence surfacing

Status: resolved
Blocked by: 04

## Objetivo

UI linka cada task/herói ao seu ledger e evidências (CHECK/EXPECT/EVIDENCE, paths de screenshots). Gate FAIL vira marcador vermelho no herói; ABANDON vira flag. Equivale ao verification report + workpad do idosal Campaigns.

## Gate

gate: esforço com 1 gate pass e 1 fail aparece corretamente na UI.
expect: cores/links corretos apontando para arquivos reais de ledger.
evidence: screenshot + paths verificados.
